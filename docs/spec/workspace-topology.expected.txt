# workspace 本地依赖拓扑期望基线（V11-66 建立）。
#
# 作用：CI 对 `cargo tree --workspace --depth 1 --no-dedupe` 的归一化输出与
# 本文件（去掉本注释头）做 diff——拓扑变更（新增/移除依赖边、Cargo.lock 版本
# 漂移）必须显式更新本文件，使「加一条依赖」成为有意识的评审事件。
#
# 归一化规则（机器无关）：删除 cargo tree 输出中所有 ` (...)` 片段。其中
# workspace 成员的绝对路径随平台变化（Windows `D:\...` vs Linux runner
# `/home/runner/...`），`(*)` 重复标记随去重状态变化，均无评审价值；
# **版本号保留**——体积红线余量仅 512 B，依赖升级可能直接吃掉它，
# Cargo.lock 漂移同样是拓扑事件。
#
# `--no-dedupe` 必须带：默认去重模式下 workspace 第二个成员（rustmark-core）
# 的直接依赖会被 `(*)` 折叠隐藏，core 新增依赖边将逃过本断言（2026-10-24 实测）。
#
# 更新方式：本地跑
#   cargo tree --workspace --depth 1 --no-dedupe | sed -E 's| \([^)]*\)||g'
# 核对 diff 确为预期变更后，把输出写回本文件（保留本注释头），随变更 commit
# 一并提交。CI 步骤见 .github/workflows/ci.yml「Workspace topology assertion」。
#
#
# 基线：2026-10-24，V11-58 抽出 rustmark-icons 后拓扑 = 两条本地依赖链在
# rustmark-actions 汇合（无环）：root → rustmark-core → rustmark-actions 与
# root → rustmark-icons → rustmark-actions（icons 依赖面 = egui +
# rustmark-actions，由 tests/workspace_topology_test.rs 断言；root 仍不直连
# actions，UiAction 经 core re-export 访问）。
#
# 基线更新：2026-10-24，V11-62 批次 1 抽出 rustmark-ui（widgets）后拓扑 =
# 三条本地链汇合（无环，本地依赖边 4 → 6 条）：
#   root → rustmark-core → rustmark-actions
#   root → rustmark-icons → rustmark-actions
#   root → rustmark-ui → rustmark-core → rustmark-actions（ui 依赖面 = egui +
#   rustmark-core，由 tests/workspace_topology_test.rs 断言）。
#
# 批次 2 复核：2026-10-25，V11-62 批次 2 搬入 state（UI State，24 文件）后
# 拓扑不变——state 对 core 的引用走既有 ui→core 边，本地依赖边仍 6 条，
# CI 式 diff CLEAN（非「忘记更新」，实测无变更）。
#
# 基线更新：2026-10-26，TD-04 抽出 rustmark-shared 后拓扑 = 四条本地链
# （无环，本地依赖边 6 → 7 条）：
#   root → rustmark-core → rustmark-shared
#   root → rustmark-core → rustmark-actions
#   root → rustmark-icons → rustmark-actions
#   root → rustmark-ui → rustmark-core → rustmark-shared
# shared 依赖面 = ahash + serde + thiserror（无任何 workspace 成员，由
# tests/workspace_topology_test.rs 的 shared_crate_declares_no_workspace_dependency
# 断言）；root 不直连 shared——公开路径经 core 的 `pub use rustmark_shared::shared;`
# 桥接。同批实测修正：V11-63 删 core 的 egui 依赖后，本文件曾漏更新（core 行
# 仍列 egui），本次按实测重生成。
#
# 基线更新：2026-10-26，V11-64 抽出 rustmark-infra 后拓扑 = 本地依赖边
# **7 → 9 条**（无环；root 直连四个成员，core / icons / ui / infra 再各出边）：
#   root → {rustmark-core, rustmark-infra, rustmark-icons, rustmark-ui}   （4 条）
#   rustmark-core   → {rustmark-actions, rustmark-shared}                  （2 条）
#   rustmark-infra  → rustmark-core                                       （1 条）
#   rustmark-icons  → rustmark-actions                                    （1 条）
#   rustmark-ui     → rustmark-core                                       （1 条）
# 计数口径：`cargo tree --workspace --depth 1 --no-dedupe` 输出里每一条
# `rustmark-*` 子项 = 一条本地依赖边；不要目测「几条链」（transitive 路径
# 会把 9 条边数成 7 条链，2026-10-26 首稿即因此误记为 8 条）。
# infra 依赖面 = rustmark-core + 解析/高亮/对话框/网络等外部库（workspace 成员
# 恰为 core 一条，由 tests/workspace_topology_test.rs 的
# infra_crate_depends_on_core_only 断言）；root 直连 infra——与 core 同一层
# 待遇（基础设施层是组合根要装配的东西），公开路径经 `pub use
# rustmark_infra::infrastructure;` 桥接后对视图零改动。
# 同批：core 的依赖面从「四层 + 全部外部适配库」收窄为
# rustmark-{actions,shared} + ahash/log/serde/thiserror，infra 承接原有外部库。
#
# 基线更新：2026-10-27，R-05 解耦 `rustmark-icons` 与 `rustmark-actions` 后拓扑 =
# 本地依赖边 **9 → 8 条**（无环）：删除 `rustmark-icons → rustmark-actions` 一条
# 边，`icons` 依赖面收敛为纯 egui（由 tests/workspace_topology_test.rs 的
# icons_crate_dependency_face_is_egui_only 断言）。当前边表：
#   root → {rustmark-core, rustmark-infra, rustmark-icons, rustmark-ui}   （4 条）
#   rustmark-core   → {rustmark-actions, rustmark-shared}                  （2 条）
#   rustmark-infra  → rustmark-core                                       （1 条）
#   rustmark-ui     → rustmark-core                                       （1 条）
#
# 基线更新：2026-10-28，R-04 升 crate 把富内容渲染引擎 `rich` 物理搬出为独立
# `rustmark-render`（默认 egui-free，唯一 egui 后端走 `feature = "egui"`，由
# rustmark-ui 经 `features = ["egui"]` 开启）。拓扑 = 本地依赖边 **8 → 9 条**
# （无环）：新增 `rustmark-ui → rustmark-render` 一条边；`icons` 仍纯 egui、
# `ui` 依赖面变为 `egui + rustmark-core + rustmark-render`（由
# tests/workspace_topology_test.rs 的 ui_crate_dependency_face_is_egui_plus_core
# 与 render_crate_egui_free_by_default 断言）。当前边表：
#   root → {rustmark-core, rustmark-infra, rustmark-icons, rustmark-ui}   （4 条）
#   rustmark-core   → {rustmark-actions, rustmark-shared}                  （2 条）
#   rustmark-infra  → rustmark-core                                       （1 条）
#   rustmark-ui     → {rustmark-core, rustmark-render}                     （2 条）
# `rustmark-render` 自身无本地依赖边（egui 为 optional 外部依赖，默认不引入）。
#
# 基线更新：2026-10-28，R-10 项 A 把 5 个架构端口契约（dialog / event / system /
# image_asset / time）从 shared 抽出为独立 `rustmark-ports`（core 经
# `pub use rustmark_ports as ports;` 拼回）。拓扑 = 本地依赖边 **9 → 12 条**
# （无环）：新增 `core → ports`、`infra → ports`、`ports → shared` 三条边
# （root 不直连 ports，端口经 `rustmark_core::ports` 间接取）。依赖面断言见
# tests/workspace_topology_test.rs 的 ports / core / infra 三处。当前边表：
#   root → {rustmark-core, rustmark-infra, rustmark-icons, rustmark-ui}       （4 条）
#   rustmark-core   → {rustmark-actions, rustmark-shared, rustmark-ports}     （3 条）
#   rustmark-infra  → {rustmark-core, rustmark-ports}                        （2 条）
#   rustmark-ui     → {rustmark-core, rustmark-render}                       （2 条）
#   rustmark-ports  → rustmark-shared                                       （1 条）
#
# 基线更新：2026-10-29，M2（R-10 项 B 补全）把组合根装配面（`production_bundle` /
# `Services` / `ConfigPaths` / `assemble_with_*`）从 root `src/app/bootstrap.rs`

# tests/workspace_topology_test.rs 的 assembly_crate_depends_on_core_infra_ports）。
