# workspace 本地依赖拓扑期望基线（V11-66 建立）。
#
# 作用：CI 对 `cargo tree --workspace --depth 1 --no-dedupe` 的归一化输出与
# 本文件（去掉本注释头）做 diff——拓扑变更（新增/移除依赖边、Cargo.lock 版本
# 漂移）必须显式更新本文件，使「加一条依赖」成为有意识的评审事件。
#
# 归一化规则（机器无关）：删除 cargo tree 输出中所有 ` (...)` 片段。其中
# workspace 成员的绝对路径随平台变化（Windows `D:\...` vs Linux runner
# `/home/runner/...`），`(*)` 重复标记随去重状态变化，均无评审价值；
# **版本号保留**——体积红线余量仅 512 B，依赖升级可能直接吃掉它，
# Cargo.lock 漂移同样是拓扑事件。
#
# `--no-dedupe` 必须带：默认去重模式下 workspace 第二个成员（rustmark-core）
# 的直接依赖会被 `(*)` 折叠隐藏，core 新增依赖边将逃过本断言（2026-10-24 实测）。
#
# 更新方式：本地跑
#   cargo tree --workspace --depth 1 --no-dedupe | sed -E 's| \([^)]*\)||g'
# 核对 diff 确为预期变更后，把输出写回本文件（保留本注释头），随变更 commit
# 一并提交。CI 步骤见 .github/workflows/ci.yml「Workspace topology assertion」。
#
#
