## 1. 环境准备

1. 在**真实 Mac** 上用 `cargo build --release` 或打包后的 `.app` 测试（未签名的 `.app` 可能在首次打开时被 Gatekeeper 拦截，需「右键 → 打开」或 `xattr -dr com.apple.quarantine`）。
2. 准备中文目录：`/Users/<你>/文档/Markdown 笔记/你好世界/`。
3. 确认系统装有 CUPS（`lp` 在 `/usr/bin`，默认随系统）。
4. 准备一台可用打印机或确认无打印机时的回退提示。
5. 确认系统中文字体存在：`ls /System/Library/Fonts/PingFang.ttc`（macOS 自带苹方，一般无需安装）。**缺失时中文将显示为方框**，见 §2.4。
6. 准备一个 **GBK 编码**的中文 `.md`（本清单 §2.5a 需要）。

### 2.3 修饰键 / 快捷键（P0，需截图）

- **MQ-M-12** 单键 `F8` / `Esc`：无修饰键可触发。
- **MQ-M-13** 改键后重启生效，旧键不残留（注册表 `rebind` 行为）。

### 2.4 字体 / CJK 渲染（P0，需截图）

> **实测结论（务必按此判断，勿凭直觉）**：egui 0.33 内置字体族**不含任何 CJK 字形**，
> 所以「macOS 上 `system-ui` 会自动经 PingFang SC 回退」这一旧假设**不成立**——
> 不显式加载中文字体时，界面中文**必然**是占位方框（`□`）。
> 现由 `infrastructure/fonts.rs` 在首帧前依次探测
> `/System/Library/Fonts/PingFang.ttc → STHeiti Light.ttc → /Library/Fonts/Arial Unicode.ttf`，
> 并**追加到字体族末尾**。这些路径**未在开发机验证过**，本节即首次真机确认。

- **MQ-M-14** 界面所有中文（菜单、工具栏、侧栏、状态栏、弹窗）显示清晰，无豆腐块（`□`）、无问号、无空白。**逐屏翻一遍**，不要只看编辑区。
- **MQ-M-14b** 状态栏、标签页标题、导出面板等**次要位置**中文同样正常。这两处字体族不同（比例族/等宽族），只验一处可能漏掉「等宽族漏挂 CJK」。
- **MQ-M-14c** 代码块内中文注释：等宽对齐不被破坏。若缩进错位，说明 CJK 字体被插到族**开头**（接管西文字形、破坏等宽），而非追加末尾。
- **MQ-M-14d** 工具栏图标（`√` / `×`）与符号面板全部条目有字形、不成方块。历史问题码位 `✓(U+2713)`、`✕(U+2715)`、`✗(U+2717)` 无字形，已换为 `√(U+221A)` / `×(U+00D7)`；符号面板另有 `▤→≡`、`▦→▣`、`ⓘ→ℹ`、`⏎→↩`、`⇒→↔`、`❝→"`、`🤔→💭`。
- **MQ-M-14e** Retina（@2x）下中文笔画不发虚、不锯齿。加载的是位图化程度不同的真实字体文件，若发现异常锐利或发糊，记录字体路径（`eprintln` 诊断或 `FOntSetup.cjk_source`）后再报。
- **MQ-M-14f** emoji（📄 ✅ ❌ ⭐ 💡）正常。这批由 egui 内置 NotoEmoji / emoji-icon-font 覆盖，与 CJK 字体是两条独立链路。
- **MQ-M-15** 字号 20px：编辑器 / 预览同步放大，行高保持。
- **MQ-M-16** 中文输入（mac 自带拼音 / 双拼）：候选框不遮挡，IME 合成中（composition）不破坏文档结构。

## 3. 平台差异处置表

| 维度 | macOS | 与 Windows 差异 | 与 Linux 差异 | 处置 |
|---|---|---|---|---|
| 主修饰键 | 物理 **⌘**（模型内 `ctrl` 字段承载） | Win 物理 Ctrl | Linux 物理 Ctrl | 字符串统一 `Ctrl+…`，分发按平台映射；显示层应呈现 ⌘ |
| 路径 | 原生 `/` | Win 需 `\→/` 归一 | 原生 `/` | 一致 |
| 打印 | `lp`（CUPS 自带） | Win 用 `powershell` | `lp`/`lpstat` | 探测文案不同 |
| 中文字体来源 | `/System/Library/Fonts/PingFang.ttc` → `STHeiti Light.ttc` → `/Library/Fonts/Arial Unicode.ttf` | `%WINDIR%\Fonts`：微软雅黑 → 等线 → 黑体 → 宋体 | `/usr/share/fonts/…`：Noto CJK → 文泉驿 → 微米黑 → 文泉驿正黑 | **egui 内置字体无 CJK，三平台均须显式加载并追加到族末尾**；缺字体不阻塞启动，仅打印明确警告。**macOS 路径未在开发机验证** |
| 文件编码 | 读取 UTF-8/BOM/GBK，保存 UTF-8 | 同 | 同 | 平台无关纯逻辑，三平台共用同一实现与测试 |
| 对话框 | Cocoa 原生 | Win32 原生 | GTK 原生 | rfd 抽象，行为一致 |
| 签名/沙盒 | 可能受 Gatekeeper / 沙盒约束 | 无 | 无 | 发行前专项 |

## 4. 已知风险 / 遗留

- **DEF-01**：大小写不敏感查找 O(N×M)，大文件卡顿。
- **DEF-02**：自动保存 / 草稿恢复运行时未接线（见 `docs/archive/stage-reports/crash-recovery-report.md`）。
- **DEF-03**：保存一律写 UTF-8，无法写回原GBK 编码。
- **DEF-04**：GB18030 / Big5 / Shift_JIS 未支持，遇这些编码可能出现替换字符。
- **DEF-05**：PNG 仅覆盖可见视口，整篇长图未实现。
- **macOS 字体候选路径未在开发机验证**——本清单 §2.4 是首次真机确认，请如实记录加载结果。
- macOS 真机不可在 CI 自动化，IME / Retina / 沙盒是本清单核心价值。
