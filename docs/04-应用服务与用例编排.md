# 阶段 04 · 应用服务与用例编排

> 阶段编号：04 ｜ 预估工期：1.5 周 ｜ 对应需求文档：§6.2、§6.5、§7.1（`src/application/`）
> 上游输入：阶段 03 冻结的聚合根与 trait 签名
> 下游输出：Command / Query / DTO / AppService 全套接口与实现，应用层单测

---

## 1. 阶段目标

把领域能力封装成**表现层可直接调用的用例接口**：表现层只见 DTO 与 Command，不见聚合根；所有跨上下文协作（如"保存文档 → 更新最近文件 → 发事件"）在应用层编排，不泄漏到 UI。

---

## 2. 输入 / 输出 / 完成标准

| 项 | 内容 |
|---|---|
| **输入** | `src/domain/**`（聚合、trait、事件）、`src/shared/**` |
| **输出** | `src/application/{document,markdown,workspace,preferences,export}/**`、`src/application/dto.rs`、`tests/application/**` |
| **完成标准（DoD）** | ① 全部 AppService 返回 `AppResult<DTO>`，签名中**不出现任何聚合根类型**；② 应用层单测（用 fake 仓储 / fake 解析器）全绿，覆盖每个 Service 的主路径与 2 条以上错误路径；③ `check-arch` 证明 application 层无 `egui` / 具体解析器 / `std::fs`；④ 自动保存、脏标记、最近文件三条事件链路有集成级用例 |

## 3. 任务清单

### S4-01 DTO 定义

- **描述**：定义表现层唯一可见的数据结构：`DocumentView { id, title, path, content_preview, is_dirty, cursor, selection, line_count, byte_len }`、`OutlineView(Vec<OutlineItemView>)`、`SearchHitView { file_id, path, line, col, snippet, match_range }`、`SettingsView { theme, editor, shortcuts: Vec<ShortcutView> }`、`ExportResultView { job_id, output_path, bytes, format }`、`RenderedView { blocks: Vec<BlockView>, version }`、`StatsView`（字数/字符/行数/标题/任务完成度/阅读时长，字段对齐原型 `StatsDialog.vue`）。
- **前置依赖**：S3-09、S3-12、S3-13
- **涉及文件**：`src/application/dto.rs`
- **验收标准**：全部 DTO `Clone + Debug + Serialize`（`Deserialize` 仅 `SettingsView` 需要）；DTO 中不含 `Document` / `Workspace` 等聚合类型（用 `cargo check` + 人工确认）；无 `Arc<Mutex<>>` 之类的内部可变共享。

### S4-02 Document Command 定义

- **描述**：`OpenFileCommand { path }`、`NewDocumentCommand`、`SaveCommand { id, save_as: bool }`、`InsertTextCommand { id, offset, text }`、`ReplaceRangeCommand { id, range, text }`、`UndoCommand { id }`、`RedoCommand { id }`、`CloseCommand { id, force: bool }`、`SetSelectionCommand { id, selection }`。每个 Command 自带 `validate()` 或由 Service 校验。
- **前置依赖**：S4-01、S3-07
- **涉及文件**：`src/application/document/commands.rs`
- **验收标准**：Command 全部为纯数据（`Clone + Debug`）；字段不含聚合引用；`CloseCommand.force` 与非 force 的语义在文档注释中写明（force=true 丢弃未保存修改）。

### S4-03 Document Query 定义

- **描述**：`GetDocumentQuery { id } -> DocumentView`、`GetContentQuery { id, range } -> String`、`GetStatsQuery { id } -> StatsView`、`GetSelectionQuery { id }`、`ListOpenDocumentsQuery -> Vec<DocumentView>`。
- **前置依赖**：S4-01
- **涉及文件**：`src/application/document/queries.rs`
- **验收标准**：Query 与 Command 命名不冲突（动名词区分）；`GetContentQuery` 支持 `range = None` 取全文（大文件场景由调用方限制）。

### S4-04 `DocumentAppService`

- **描述**：编排文档用例。依赖：`DocumentRepository`（trait，领域层定义）、`EventBus`、`UndoStack` 状态由聚合持有。关键流程：**保存** = 取内容 → 仓储 `save`（原子写由基础设施保证）→ 聚合 `mark_saved` → 发 `DocumentSaved` → 触发最近文件更新（通过事件，不直接调 Workspace service）；**打开** = 仓储 `load` → 建聚合 → 发 `DocumentOpened`；**关闭** = 脏检查 → 返回 `NeedsSave` 决策给表现层。
- **前置依赖**：S4-02、S4-03、S3-06 ~ S3-08、S3-11（Repository trait）
- **涉及文件**：`src/application/document/service.rs`、`tests/application/document_service_test.rs`
- **验收标准**：单测 ≥ 15 条；覆盖：打开不存在文件返回 `Err`、保存失败时聚合**不**被标记 clean（关键：失败不得丢脏标记）、关闭脏文档且 `force=false` 返回 `NeedsSave`、`undo` 空栈返回 `Err(UndoStackEmpty)`、保存成功后事件队列含 `DocumentSaved` 且 ID 正确。

### S4-05 Markdown Query / Command

- **描述**：`RenderPreviewQuery { doc_id, version } -> RenderedView`、`HighlightQuery { doc_id, range, lang } -> Vec<SpanView>`、`MapScrollQuery { doc_id, source: ScrollSource, position } -> ScrollTarget`（滚动同步的核心用例，输入编辑区/预览区的滚动位置与比例，输出对侧目标位置）、`RebuildOutlineQuery -> OutlineView`。
- **前置依赖**：S3-09、S3-10
- **涉及文件**：`src/application/markdown/{commands.rs,queries.rs}`
- **验收标准**：`MapScrollQuery` 语义文档化（比例映射算法、块内插值、命中空隙时的稳定吸附规则）；单测用 fake parser 验证：块首/块中/块尾三处映射、预览区点击标题 → 编辑区跳转到对应行。

### S4-06 `MarkdownAppService`（含防抖策略）

- **描述**：编排渲染与高亮，持有 `RenderCache`（`version -> RenderedView`，LRU 上限按 §8.3 设定）。**防抖策略（FR-01，150ms）下沉到应用层**而非 UI：定义 `DebouncePolicy { interval: Duration }` 与纯函数 `should_render(last_edit, now, policy) -> bool`，可单测，避免 UI 层用 `setTimeout` 类写法导致行为不可测。
- **前置依赖**：S4-05、S3-10
- **涉及文件**：`src/application/markdown/service.rs`、`tests/application/markdown_service_test.rs`
- **验收标准**：单测覆盖：距上次编辑 <150ms 不触发、≥150ms 触发、连续输入只保留最后一次、缓存命中不重新解析（断言 fake parser 调用次数）；大文件标记（`> 500KB`）时返回 `RenderedView { truncated: true }` 供 UI 降级（FR-06 的应用层判定）。

### S4-07 `WorkspaceAppService`

- **描述**：文件树（列出、新建、重命名、删除、移动）、最近文件（上限 20、去重）、标签页（打开/关闭/激活/全部保存）、跨文件搜索（`SearchQuery { pattern, regex, case_sensitive, whole_word } -> Vec<SearchHitView>`，含命中上限保护：单文件 50、总 300，与原型一致）。搜索走 `WorkspaceRepository` 提供的遍历能力，覆盖未保存草稿。
- **前置依赖**：S3-11、S4-01
- **涉及文件**：`src/application/workspace/{commands.rs,queries.rs,service.rs}`、`tests/application/workspace_service_test.rs`
- **验收标准**：单测 ≥ 12 条；覆盖：最近文件去重与上限裁剪、搜索命中上限截断并报告 `truncated`、搜索覆盖未保存草稿（断言用的是 draft 内容而非磁盘内容）、删除文件后标签页同步关闭。

### S4-08 `PreferencesAppService`

- **描述**：主题读写（含 `System` 跟随）、编辑器设置、快捷键自定义。`SetShortcutCommand { action, combo }` 必须**先调领域层 `Conflicts::detect`**，有冲突时返回 `Err(ShortcutConflict { conflicting_action })` 而不是静默覆盖（原型缺陷 1.1-D 根治）；设置变更后发 `PreferencesChanged` 事件，UI 与应用层订阅者据此刷新。
- **前置依赖**：S3-12、S4-01
- **涉及文件**：`src/application/preferences/{commands.rs,queries.rs,service.rs}`、`tests/application/preferences_service_test.rs`
- **验收标准**：单测覆盖：设置冲突 combo 返回 Err 且不落库、功能键（F8）可成功绑定（原型缺陷 1.1-A 根治）、改键后 `SettingsView.shortcuts` 与菜单/命令面板共用同一份数据（断言三处取值来自同一 `ShortcutView` 源）、持久化失败返回 Err 不静默。

### S4-09 `ExportAppService`

- **描述**：`CreateExportJobCommand { doc_id, format, options }`、`RunExportCommand { job_id } -> ExportResultView`。流程：领域 `ExportJob::validate()` → 取文档内容 → 调 `Exporter` trait（基础设施实现）→ 产出结果并发 `ExportFinished`。PDF 为 P1，未实现时返回明确 `Err(Unsupported { format })`。
- **前置依赖**：S3-13、S4-01
- **涉及文件**：`src/application/export/{commands.rs,queries.rs,service.rs}`、`tests/application/export_service_test.rs`
- **验收标准**：单测覆盖：非法选项组合被领域 `validate` 拒绝且不调用 Exporter、TOC 选项下传给 Exporter 且带 `needs_escape` 标记、Exporter 失败时返回 `Err` 且 job 状态标记为 failed、PDF 未实现时错误文案明确。

### S4-10 事件订阅与跨上下文编排

- **描述**：在应用层订阅领域事件完成跨上下文协作：`DocumentSaved` → 更新最近文件；`TextModified` → 推进自动保存计时（按 `auto_save_interval`）；`PreferencesChanged` → 通知 Markdown 服务失效缓存（主题影响渲染）。定义 `EventSubscribers` 装配点，由 `app.rs`（阶段 06）注入。
- **前置依赖**：S4-04、S4-07、S4-08、S2-06
- **涉及文件**：`src/application/event_subscriptions.rs`、`tests/application/event_flow_test.rs`
- **验收标准**：集成级用例：模拟「输入 → 修改 → 自动保存 → 最近文件更新」全链路，断言最近文件列表首项正确；订阅者 panic/失败不阻断主流程（返回 `Err` 由调用方记录）；无重入死循环（如自动保存再次触发 `TextModified`）— 单测断言事件计数上限。

### S4-11 应用层测试与 fake 基础设施

- **描述**：为阶段 05 未就绪的外部依赖建立 fake：`InMemoryDocumentRepository`、`FakeMarkdownParser`（返回预定义块）、`FakeHighlighter`、`InMemoryPreferencesRepository`、`InMemoryEventBus`。全部放在 `tests/` 或 `src/application/testing.rs`（`#[cfg(feature = "test-utils")]`，避免进 release 产物）。
- **前置依赖**：S3-02、S3-10
- **涉及文件**：`tests/common/fakes.rs`、`tests/application/**`
- **验收标准**：fake 与真实实现共享同一 trait（编译期保证）；`cargo test` 全绿；确认 `test-utils` feature 默认关闭，`cargo build --release` 不含 fake 代码（`cargo bloat` 对比前后体积变化 < 10KB）。

## 4. 技术方案要点

- **DTO 边界是硬边界**：AppService 签名里出现聚合根即视为架构违规（人工 review + `check-arch` 增加「application 不得引用 `domain::*::aggregate`」的可选规则）。
- **防抖与缓存在应用层**：把时间相关策略做成可注入的 `DebouncePolicy` / `Clock`，使单测可控（原型把 150ms 防抖写在组件里，无法单测，这是可测性上的教训）。
- **事件是通知不是命令**：事件订阅者只做「更新派生状态」，不反向修改触发事件的聚合，避免循环。
- **失败语义优先**：保存失败不得清除脏标记、导出失败不得标记成功——这类「失败路径的状态一致性」是本阶段单测的重点（原型 2.1 的静默失败是反面教材）。

## 5. 风险与注意事项

| 风险 | 等级 | 表现 | 应对 |
|---|---|---|---|
| DTO 与原型字段不一致 | 中 | 阶段 06/07 对齐时返工 | S4-01 阶段就对照原型 `StatsDialog.vue` / `SettingsDialog.vue` / `GlobalSearchPanel.vue` 的字段清单逐项对齐 |
| 应用层变成"贫血转发层" | 中 | Service 只是调用聚合方法，编排逻辑反而散落到 UI | 每个 Service 至少承担 1 项跨上下文协作（事件、缓存、事务边界），否则合并到聚合 |
| 自动保存与用户输入竞争 | 中 | 保存期间用户继续输入导致内容不一致 | 保存前取内容快照；保存失败不清除脏标记；阶段 07 用真实节奏验证 |
| 缓存失效不彻底 | 中 | 主题/设置变更后预览仍是旧样式 | 缓存 key 必须包含 `theme_version` 与 `content_version`；S4-10 订阅 `PreferencesChanged` 主动失效 |
| fake 与真实实现行为漂移 | 中 | 单测全绿但集成失败 | 阶段 05 完成后，对同一组 golden 输入同时跑 fake 与真实实现，比对输出（阶段 07 执行） |
| 搜索性能（同步全量扫描） | 低 | 大工作区卡顿 | 保持原型同款上限（50/300）；阶段 08 评估是否需要异步化 |

## 7. 本阶段修复的缺陷

S4-11 的集成测试暴露出三个**真实缺陷**（非测试写法问题），已修复：

1. **订阅者回调重入注册表导致死锁**（严重）。
   `DocumentAppService::save()` 等方法在**持有注册表写锁**期间调用
   `publish_doc_events()` 发布 `DocumentSaved`；而 `EventSubscribers` 的
   `DocumentSaved` 处理会经`DocumentContentProvider::path_of()` 反向读取同一把
   `RwLock`。`RwLock` 不可重入，同线程重入直接死锁——集成测试挂起 10 分钟才暴露。
   修复：拆分为 `drain_doc_events()`（锁内取事件）与 `publish_all()`（**锁外**发布），
   `save` / `insert_text` / `replace_range` / `undo` / `redo` / `set_selection`
   全部改为「锁内变更 → 释放锁 → 发布」。

2. **任务列表计数漏统计未勾选项**。
   `compute_stats()` 去掉 `- [` 前缀后未修剪残留空格，`- [ ] todo` 的剩余部分为
   `" ] todo"`，`starts_with(']')` 恒为 false，导致未完成任务不计入 `tasks_total`。

3. **`EventBus::subscribe` 签名阻塞共享后注册**。
   原为 `&mut self`，组合根无法把总线包成 `Arc<dyn EventBus>` 后再注册订阅者。
   改为 `&self`（实现方本就使用内部可变性）。

此外修复了 `event_subscriptions` 模块从未在 `src/application.rs` 中声明、
因而从未被编译的问题。
